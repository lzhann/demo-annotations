Demo 批注组件包

一套可以放进其他 Demo 的批注工具。无需安装依赖或启动后端。

打开可操作示例

最快接入

将下面两个文件复制到你的 Demo 根目录，然后在页面中加入：

<link rel="stylesheet" href="demo-notes.css">
<script src="demo-notes.js" data-project="你的Demo独立编号" defer></script>

给希望精确定位的卡片增加稳定标识：

<section data-note-id="sales" data-note-label="销售额">
  ...原有页面内容...
</section>

包内内容

  • demo-notes.js / demo-notes.css：核心组件，普通 HTML 页面直接引用。
  • README.md：配置、Tab/范围隔离、SPA 接入和 API 说明。
  • 给AI的接入提示词.txt：交给其他 Demo 的开发助手使用。
  • examples/：两页示例，可验证跨页面定位、Tab 和范围切换。
  • tests/：验收测试脚本，供开发者选用。

首次打开没有预置备注。备注保存在当前浏览器；需要换电脑或交给同事时，使用“备注汇总 → 备份与导入”。
